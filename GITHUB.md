# GitHub-Update / Installation

## Neues Repository
1. ZIP entpacken.
2. GitHub Desktop → File → New repository.
3. Name z. B. `IPSymcon-LCNClimateControl`.
4. Repository → Show in Explorer.
5. Inhalt des entpackten Ordners hineinkopieren. `.git` nicht löschen.
6. Commit: `Initial release 0.1.0`
7. Publish repository (öffentlich).
8. In Symcon → Kern Instanzen → Modules → Repository-URL hinzufügen.

## Spätere Updates
Immer den **gesamten Repository-Inhalt** ersetzen, aber `.git` beibehalten.
Die Versionsnummer und `build` in `library.json` müssen bei jedem Update steigen.
